### Chattanooga State Digital Development Club's 
*Discord Bot Project*

## Introduction
This is the Digital Development Club @ Chattanooga State's Discord bot creation project! This is where the club will be creating a Discord bot to manage the Digital Development Club server. This project is based on the ``discord.js`` dependency.

## Installation
1. Install [Node.js](https://nodejs.org/en/download) version 26.3.0 or above.
2. Download [this repository's](https://github.com/digitaldevelopmentcluba-dot/discordBotsP) source. Extract the contents to wherever you like!
3. Create a ``.env`` file and put the following inside: ``token=<bot token goes here>``.
4. ``cd`` into the directory.
5. Run ``npm run start``!

## Features
* Modular-driven architecture (events, commands, etc.)
* Automatic event handling
* Automatic command registration
* Full-sharding support
* Client <-> shard manager messaging (IPC)
