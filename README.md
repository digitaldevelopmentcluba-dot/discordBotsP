### Chattanooga State Digital Development Club's 
*Discord Bot Project*

## Introduction
This is the Digital Development Club @ Chattanooga State's Discord bot creation project! This is where the club will be creating a Discord bot to manage the Digital Development Club server. This project is based on the ``discord.js`` dependency.
